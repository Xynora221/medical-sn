# Médical-SN

Plateforme web de santé pour le Sénégal : prise de rendez-vous médicaux et téléconsultation, pour rapprocher patients et médecins.

## Pourquoi ce projet ?
Faciliter l'accès aux soins en permettant aux patients de s'inscrire, de réserver un rendez-vous et, à terme, de consulter un médecin à distance.

## Fonctionnalités
- Inscription et connexion patient
- Tableau de bord patient
- Prise de rendez-vous
- Téléconsultation (à venir)
- Dossier médical et services de l'hôpital (à venir)
- Espace médecin (à venir)

## Technologies
- React (Vite)
- React Router
- Bootstrap

## Lancer le projet
bash
npm install
npm run dev
